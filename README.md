# The Chrome Pilgrim

A modern e-commerce experience built with **React** for showcasing and purchasing the iconic **Chrome Pilgrim Sleeves**. Inspired by the futuristic, gothic aesthetic of the original wearable art piece, the website combines immersive visuals with a clean shopping experience.

---

## ✨ Features

- Modern, responsive user interface
- Product image gallery with autoplay carousel
- Smooth navigation with React Router
- Product detail pages
- Shopping cart functionality
- Responsive design for desktop, tablet, and mobile
- Clean and immersive shopping experience

---

## 🛠️ Tech Stack

- React
- React Router
- JavaScript (ES6+)
- CSS3

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Manuelthegoat/thechromepilgrim.git
```

### Navigate into the project

```bash
cd thechromepilgrim
```

### Install dependencies

```bash
npm install
```

### Start the development server

If you are using Create React App:

```bash
npm start
```

If you are using Vite:

```bash
npm run dev
```
